# GitHub + Render · Etapa 1

## 1. Crear repositorio privado en GitHub

Subí **el contenido de esta carpeta**.

Nombre sugerido:

`tm-asociados-gestion-juridica`

## 2. Crear Static Site en Render

- New > Static Site.
- Conectar GitHub.
- Seleccionar el repositorio.
- Branch: `main`.
- Build Command: dejar vacío.
- Publish Directory: `.`

También podés usar el `render.yaml` incluido.

## 3. Validación

Una vez publicada la URL:

1. Abrir en PC.
2. Crear un cliente ficticio.
3. Crear un caso ficticio.
4. Modificar estado, prioridad y riesgo.
5. Registrar una actuación.
6. Adjuntar un PDF de prueba sin información sensible.
7. Cerrar y volver a abrir la página en el mismo navegador.
8. Confirmar que el PDF sigue disponible.

En otro dispositivo NO aparecerán todavía los datos. Es correcto: eso se resolverá en la etapa Google Drive + Sheets.
